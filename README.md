## 本機預覽

在專案根目錄執行以下指令，開啟 [本機網站](http://127.0.0.1:8000/)。

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

`index.html` 是首頁，`assets/` 放置樣式、腳本、字型與媒體。網站無須建置。
