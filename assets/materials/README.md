# 晚會網站素材

- `brand/header-logo.ico` 為頁首 Logo。
- `brand/hero-watermark.png` 為首屏浮水印。
- `brand/ticket-watermark.png` 為票券浮水印。
- `journal/` 按貼文主題命名，包含 Portugal Airlines 照片、Upside Down 影片及主題發布海報。
- `source/` 保留未壓縮原圖。網站使用 `brand/` 和 `journal/` 下的版本。
- `examples/` 保留原先的 Logo 範例。

替換素材時請保留真實副檔名。若檔名或格式變更，請同步更新 `index.html` 的引用。
